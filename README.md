# Koyori

Koyori is a personal customized WordPress theme maintained for Smallmaple.
It is a derivative work based on [Sakurairo](https://github.com/mirai-mamori/Sakurairo), originally created by Fuukei / mirai-mamori.

## Upstream

- Original theme: Sakurairo
- Upstream repository: https://github.com/mirai-mamori/Sakurairo
- Upstream author/project: Fuukei / mirai-mamori
- Upstream license: GNU General Public License v2.0 or later

Koyori retains the upstream copyright and license notices. Upstream changes
may be reviewed and merged selectively rather than applied automatically.

## Koyori changes

- Smallmaple navigation alignment improvements
- WordPress login-page visual fixes
- PJAX compatibility fix for login links
- Personal visual customization for the Smallmaple blog
